# POLSKI (PL)

## Zone 48

Zone 48 to projekt robiony w ramach ogólnopolskiej Olimpiady *"Zwolnieni z Teorii"*. Celem projektu jest pogłębienie wiedzy o Toruniu oraz aktywizacja sportowa. Chcemy to osiągnąć poprzez tę stronę internetową gdzie użytkownicy mogą zdobywać zniżnki do partnerskich sklepów czy restauracji poprzez wykonywanie różnych zadań sportowych lub poprawne odpowiadanie na pytania związane z Toruniem.

# ENGLISH (EN)

## Zone 48

Zone 48 is a project carried out as a part of a nationwide "Zwolnieni z Teorii" Olympiad. The project aims to deepen the knowlegde about Toruń and encourage people to participate in sport activities. We aim to achieve this via this website where users can earn discounts at our partner stores and restaurants by completing various tasks connected with sports or correctly answering questions about Toruń.
